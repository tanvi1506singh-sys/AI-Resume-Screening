# AI Resume Screening System

## Project Description
AI Resume Screening System is a Python-based web application that analyzes a resume and checks the skills mentioned in it. It calculates a resume match score and shows missing skills and improvement suggestions.

## Features
- Upload resume in PDF format
- Extract text from PDF
- Detect skills from the resume
- Calculate ATS match score
- Display detected skills
- Display missing skills
- Provide resume improvement suggestions

## Technologies Used
- Python
- Streamlit
- PyPDF2
- NumPy
- Git and GitHub

## How to Run

1. Activate the virtual environment.
2. Install the required packages.
3. Run the Streamlit application.

```bash
streamlit run app.py
